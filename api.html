MemeAPI documentation

Secure, rate-limited funny content for your apps.

Quick start

Send a GET request with an API key in the X-API-Key header.

curl -H 'X-API-Key: mk_your_key' /api/v1/roast

Security protections

  • API-key authentication; keys are never returned or logged.
  • Per-IP rate limiting and small JSON body limits.
  • Helmet headers, CSP, no-store caching, strict CORS, and safe text sanitization.
  • GET-only content endpoints reduce CSRF exposure; do not place keys in URLs.

Accessibility

This documentation uses semantic landmarks, a skip link, labelled sections, visible keyboard focus, readable contrast, and responsive text. No focus trap is used because this page has no modal interaction.
